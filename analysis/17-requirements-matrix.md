# Документ №17. Матрица требований, зависимостей и критериев приёмки

**Актуализация U9 (26.11.2026, ред. 2).** Разделы §3–§5 и §7 заменены: собственный failover, DNS Manager, Quick Block/три режима UDP и Blocklists в U9 не реализуются. Дополнительно выведены статистика, общий журнал событий, аналитический экспорт и мониторинг ресурсов (REQ-092…REQ-095, REQ-098, REQ-102). Требование о трафике роутера получило действующий ID **REQ-165**; прежняя редакция REQ-035 остаётся superseded. Реестр superseded — §15, действующие требования U9 — §16. ID прежних требований не переиспользуются и не перенумеровываются.

Дата: 22.11.2026
Основание: ТЗ v1.0 §18.8 (матрица требований) и §19 (критерии приёмки); решения №1–82 (документ №16).
Статусы: **[У]** утверждено, **[П]** предлагается агентом, **[Т]** требует измерения/теста, **[О]** открытый вопрос.
Класс объёма: **v1** — обязательно; **lite** — облегчённая реализация; **meas** — после измерений; **defer** — отложено (документ №22).
Этапы — по ТЗ §16: 0 актуализация, 1 skeleton (daemon + LuCI, без реальных сетевых функций), 2 локальная разработка/эмуляция, 3 контролируемые сетевые функции, 4 тесты на AX3000T.

## 7. Blocklists — **исключены (superseded U9)**

Собственная подсистема Blocklists в U9 не реализуется и не откладывается. **Superseded, не действуют:** REQ-070, REQ-071, REQ-072, REQ-073, REQ-074, REQ-075, REQ-076, REQ-077, REQ-078, REQ-079, REQ-080, REQ-081, REQ-082, REQ-083, REQ-084, REQ-085, REQ-086, REQ-087, REQ-088.

Причины: Blocklists (AdBlock, реклама/трекеры, Malware/Phishing, whitelist, `temp_blocklist_off`, DNS-фильтрация, индивидуальные наборы, статистика, Quick Block) исключены решением владельца U9; P4/User BLOCK и System Protected List также исключены. ID сохранены как история и не переиспользуются.

Замена: пользователь ставит специализированные пакеты OpenWrt (Adblock, AdGuard Home) самостоятельно; VPN Manager не является DNS-фильтром. Действующая модель — №18 (L1–L4, без блокирующих уровней).
