# Документ №17. Матрица требований, зависимостей и критериев приёмки

Дата: 22.11.2026
Основание: ТЗ v1.0 §18.8 (матрица требований) и §19 (критерии приёмки); решения №1–82 (документ №16).
Статусы: **[У]** утверждено, **[П]** предлагается агентом, **[Т]** требует измерения/теста, **[О]** открытый вопрос.
Класс объёма: **v1** — обязательно; **lite** — облегчённая реализация; **meas** — после измерений; **defer** — отложено (документ №22).
Этапы — по ТЗ §16: 0 актуализация, 1 skeleton (daemon + LuCI, без реальных сетевых функций), 2 локальная разработка/эмуляция, 3 контролируемые сетевые функции, 4 тесты на AX3000T.
