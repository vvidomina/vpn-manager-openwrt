## 1. Утверждённая граница v1, принятая за критерий проверки

| Положение | Источник | Как применено |
|---|---|---|
| Пользовательский VPN-трафик — только IPv4 | ТЗ §5, решение №10 (№16) | политика IPv4-only во всех документах |
| IPv6 Guard не реализуется | ТЗ §5, решение №11 | компонент, цепочки, состояния, API и события — только архив v2 |
| Обнаружение глобального IPv6 не реализуется | ТЗ §5, решение №11 | убрано из этапов, API, критериев, объёма |
| IPv6-фильтры и специальные правила не создаются | ТЗ §5, решение №11 | «ноль IPv6-объектов» в №10/№11/№14 |
| IPv6-тесты запрещены | ТЗ §5, решение №13 | T-01 не выполняется, W-01 запрещён и не является условием |
| Настройки IPv6 OpenWrt не изменяются | ТЗ §5, решение №12 | подтверждено в №10 §9 и №17 REQ-011 |
| Риск IPv6 bypass принят пользователем | ТЗ §5, решение №14 | R3-01 во всех упоминаниях — принятый риск, а не задача |
| P-01 закрыт — вне v1 | решение №11 | во всех документах статус «закрыт — вне v1» |

Классификация упоминаний, введённая при проверке (и выдержанная в текстах):

- **(Д)** действующее ограничение v1 — остаётся без изменений;
- **(Ф)** исторический факт обследования роутера — сохранён, но не выдаётся за требование;
- **(И)** историческое требование/рекомендация прежней редакции — помечено как заменённое ТЗ §5;
- **(А)** архивный задел v2 — только в явно обозначенных архивных разделах, без команд и критериев v1.
